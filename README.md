Эко-активист: страница «О себе»
Учебный проект для освоения базовой структуры HTML, семантических тегов и работы с формами.

Цель проекта
Освоить:
* базовую структуру HTML-документа;
* семантические теги (<header>, <main>, <section>, <aside>, <footer>);
* работу с текстом, списками, ссылками и изображениями;
* создание формы обратной связи.

Что реализовано

* Семантическая разметка: вся страница собрана на блочных тегах, а не только на <div>.
* Навыки и проекты: навыки представлены в виде маркированного списка, проекты - в виде нумерованного.
* Боковая панель: блок <aside> с личными эко-привычками и формой обратной связи.
* Изображение: аватар с обязательными атрибутами src, alt, width, height.
* Форма: поля «Имя», «Email», «Сообщение» с атрибутами name и placeholder, кнопка отправки.
* Стили: базовые CSS-стили внутри <style> для зелёно-белой цветовой гаммы.

 Как запустить

1. Откройте файл "About me.html" в любом браузере
